# 🧩 MazeMaker – Interactive WebGL Maze Generator

MazeMaker is a simple but dynamic 2D maze generator built with **WebGL**.  
It renders a maze directly in the browser and allows interactive resizing using keyboard input.

---

## 🌐 Overview

- Built with **WebGL** for efficient browser-based rendering.
- Displays a randomly generated **2D maze**, initially sized **3×2**.
- Pressing **`B`** increases both the width and height of the maze by one unit (e.g., 3×2 → 4×3 → 5×4...).
- Great for visualizing procedural generation and practicing low-level web graphics.

---

## 🎮 Controls

| Key | Action                      |
|-----|-----------------------------|
| `B` | Increase maze size by +1 on both width and height |

---

## 🧱 Features

- Real-time rendering of mazes using WebGL
- Keyboard-interactive maze resizing
- Simple interface for exploring maze generation logic
